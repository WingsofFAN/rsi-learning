# RSI Learning · 递归自我改进学习项目

按照人工智能递归自我改进（Recursive Self-Improvement，RSI）的发展路径，整理经典论文、代表性技术、近期前沿和实践学习材料。

## 开始阅读

阅读 [RSI：经典论文与学习路线](./RSI_递归自我改进_经典论文与学习路线.md)。

学习文档包括：

- 1965—2026 年的 26 篇主线论文，按发展路径组织。
- 每篇论文的核心思路、贡献、实现机制、实验或理论结果，以及适用边界。
- 5 篇延伸文献，以及课程、教材、论文原文和作者代码仓库链接。
- 八周学习计划、实践实验方案和论文阅读卡片模板。

## 项目结构

目前项目以学习文档为主；文中的实践代码是示意性伪代码，并非已经实现和验证的论文复现程序。原论文实现请使用文档中列出的作者代码仓库。

## 阅读与使用说明

文献整理与在线核对日期：**2026-10-08**。后续链接、代码与论文版本可能变化，请以原作者发布的信息为准。

“自我改进”的具体对象可能是模型权重、提示词、记忆、程序或改进算法。文档区分这些情形，并注明哪些工作提供理论论证、哪些提供实验结果。近期研究与历史经典分开说明。

本项目对论文的实验结果进行文献整理，没有在本地复现实验。第三方论文和代码的使用条件以各自原始来源为准。
